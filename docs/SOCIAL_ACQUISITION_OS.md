# CryptoAID Social Acquisition OS v1

One acquisition brain, two primary channels: LinkedIn and Telegram.

## Pipeline
DISCOVER -> ATTRACT -> EDUCATE -> PROVE -> CAPTURE -> QUALIFY -> CONVERSE -> CASE -> CONVERT -> RETAIN -> REFERRAL

## Source framework adopted
The implementation adapts the uploaded LinkedIn Mastery framework rather than copying its copy: authority positioning; four content pillars; niche lead magnets; demand signals; progressive conversations; offer routing; KPI tracking; iterative optimization.

## Channel roles
- LinkedIn: founder authority, professional education, case studies, lead magnets, qualified conversations. Publishing/inbox integration must use manual workflows or official permitted APIs; no scraping or gray-hat automation.
- Telegram channel: official news, educational content, proof, lead magnets and calls to action.
- Telegram group: community, questions, polls, education, moderation and support.
- Telegram bot: bilingual EN/IT support, safety triage, intent recognition, qualification and routing toward a CryptoAID Case when appropriate.

## Safety and trust
Never request seed phrases, private keys, passwords or 2FA. Never guarantee fund recovery. Prefer public transaction hashes, public addresses, contract addresses and public URLs. Escalate uncertain/high-risk situations to a human.

## Shared intent model
Signals receive weights and map to: cold -> aware -> engaged -> problem_aware -> case_ready -> customer. The model is intentionally simple, explainable and privacy-minimal for v1.

## Content pillars
1. Social proof
2. Web3 intelligence / trends
3. Educational
4. Founder / behind the scenes

## Core lead magnets
Crypto Scam Emergency Checklist; Dead Token Survival Guide; Rug Pull Evidence Checklist; Web3 Recovery First 24 Hours; Dead DApp Atlas; Wallet Exposure Checklist; CryptoAID Case Pre-Assessment.

## Conversion target
Do not optimize for followers alone. Track qualified engagement -> qualified lead -> case started -> paid case -> revenue per qualified case -> referral.
