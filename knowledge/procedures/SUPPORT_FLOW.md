# Support Flow

USER QUESTION → LANGUAGE IT/EN → INTENT → VERIFIED KNOWLEDGE → CONFIDENCE CHECK

If confidence is sufficient:
ANSWER → SECURITY NOTE if relevant → NEXT STEP.

If confidence is insufficient:
DO NOT INVENT → HUMAN ADMIN ESCALATION.

Supported intents include CryptoAID, services, security, scam, wallet, blockchain, Web3, tokens, dApps, recovery, official links, reports, technical support and partnerships.
