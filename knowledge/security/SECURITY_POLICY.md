# CryptoAID Security Policy

## Absolute rules
- Never request seed phrases, private keys, passwords or 2FA codes.
- Treat unsolicited support DMs as suspicious.
- Verify usernames, domains and official links.
- Do not approve wallet signatures you do not understand.
- Never promise guaranteed profits or guaranteed recovery.
- High-risk or ambiguous cases require human review.

## Moderation
ALLOW → REMINDER → WARNING → TEMPORARY RESTRICTION → ADMIN ESCALATION → BAN.
Automatic bans are reserved for configured high-confidence cases.
