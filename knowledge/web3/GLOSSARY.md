# Web3 Core Glossary

- Wallet: software/hardware used to manage blockchain accounts and signatures.
- Seed phrase: recovery secret for a wallet. Never share it.
- Private key: secret cryptographic key controlling an account. Never share it.
- Smart contract: program deployed on a blockchain.
- Token: blockchain-based digital asset/unit governed by a smart contract or protocol.
- dApp: decentralized application interacting with blockchain infrastructure.
- DEX: decentralized exchange.
- DeFi: decentralized financial protocols.
- Bridge: protocol for moving/representing assets or messages across networks.
- Gas: fee paid for blockchain computation/transactions.
- Transaction hash: public identifier for a blockchain transaction.
